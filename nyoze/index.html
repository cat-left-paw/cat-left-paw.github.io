Nyoze Vertical-writing Markdown editor

縦書きでそのまま文章を書けるデスクトップエディタです。小説やエッセイを、見た目に近い画面で執筆し、テキストファイルとして保存できます。

beta 公開中 — 執筆体験と原稿の保全を優先して開発しています。次回リリースでは、書庫と作品管理を中心とした仕様変更・機能追加を予定しています。公開済みの機能と開発中の機能は、下記で分けて記載しています。

こんな方に向いています

  • 小説や文章を縦書きで書きたい
  • Markdown を使いたいが、難しい操作は避けたい
  • テキストファイルで原稿を管理したい
  • ルビや縦中横を使いながら日本語を書きたい

現在公開中の機能

以下は、現在 GitHub / Microsoft Store などで配布している beta 版に含まれる主な機能です。

執筆・編集

  • 縦書き・横書きの切り替え、WYSIWYG 編集
  • ルビ・縦中横（青空文庫形式など）、傍点
  • Typewriter scroll、編集ブロックハイライト、現在行ハイライトなどの執筆補助
  • 文書タイプ（Novel / Article）による改行ポリシーの切り替え
  • 段落単位（Paragraph Plain）・全文（Source Mode）の Markdown ソース編集
  • 検索 / 置換、見出しの折りたたみ、アウトラインパネル
  • リストのアウトライナー的な操作
  • `.md` / `.txt` の読み書き（UTF-8）

テーマ・表示

  • 豊富な内蔵テーマの切り替え（縦書き・横書きそれぞれに対応）
  • GUI からのカスタムテーマ作成・編集（Theme Studio）
  • 文書テーマと UI テーマの管理、テーマ選択メニューでの色プレビュー表示
  • 表示設定（フォント、行間、執筆補助表示など）の調整

ファイル・表示

  • 複数タブでの文書表示と編集
  • File Explorer からのファイル作成・名前変更・複製・移動・削除
  • frontmatter の読み取り、Document Settings からの限定編集
  • ローカル画像参照付き Markdown の表示

詳細は GitHub の README と MANUAL を参照してください。

開発中の機能（次回リリース以降）

開発版では実装が進んでいますが、まだ公開配布には含まれていません。内容・仕様はリリース前に変更される場合があります。

書庫・作品管理（次回リリースの中心）

次回リリースでは、これまでの「単独ファイル中心」の運用から、書庫と作品を軸にした管理へ拡張する予定です。

  • 書庫 — 複数の原稿フォルダを登録・切り替え（Vault に近い運用）
  • 作品 — `.nyoze/project.json` を持つフォルダ単位での管理
  • Book / Materials — 本編・外伝・資料などの登録と並び替え（`.nyoze/books.json`）
  • 作品内付箋（本文位置へ紐づくメモ、タグ、解決済み管理）
  • Book 全体のアウトライン、前章 / 次章ナビゲーション
  • 右ペインでの文書メタデータ（frontmatter）編集

ブロック装飾（次回リリースの大型追加）

段落やブロック単位のレイアウトを、Markdown 本文に残したまま編集・表示する機能です。ツールバーや右クリックメニューのブロック装飾から操作できるようになる予定です。

  • align — 中央寄せ（:::align-center）、行末寄せ（:::align-end）
  • indent — 段階的な字下げ（:::indent-1 〜 :::indent-6）
  • page-break — 改ページ（:::page-break）、意図的な空白ページ（:::blank-page）
  • style — 手紙風・控えめ・見出し風などの semantic style（:::style-<id>）

外部書き出し（HTML、LeME、でんでん、青空文庫風など）への反映も開発版で進めています。

Page Viewer（実装間近）

改ページやページ区切りを踏まえて、本文をページ単位で閲覧する軽量ページビューアです。ブロック装飾とあわせて、執筆した見た目に近い形で原稿を読み返すための機能として追加する予定です。厳密にはまだ公開配布に含まれていませんが、実装を仕上げて次回リリースに間に合わせる見込みです。

その他の開発中機能

  • 擬似キャレット（表示設定から調整可能）
  • 単独文書・Book 全体の HTML 書き出し
  • LeME 互換 Markdown、でんでん向け Markdown、青空文庫風テキストへの書き出し
  • 改ページ・目次・作品情報などの書き出しオプション

対応環境（公開 beta）

  • macOS（Apple Silicon / Intel）
  • Windows（Microsoft Store、GitHub Releases の zip）
