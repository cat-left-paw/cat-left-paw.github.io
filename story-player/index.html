（仮）Story Player Obsidian plugin for branching narratives — working title

Obsidian の Markdown ノートを、選択式 ADV・ゲームブック風に再生するプラグインです。専用記法を最初から覚えるのではなく、Wiki リンクと frontmatter で分岐ストーリーを書くことを重視しています。

未公開（近日公開予定） — 名称は仮です。Obsidian Community Plugin としての公開に向けて開発・検証を進めています。公開リポジトリと配布ページは、公開のタイミングで整備します。

こんな方に向いています

  • Obsidian で分岐物語やゲームブックを書きたい
  • Twine や Ink のような専用記法より、Markdown のまま書きたい
  • フラグや変数を使った条件分岐を試したい
  • 制作中に Story Map で構造を確認したい

主な機能（開発中）

公開版に含める予定の機能です。リリース前に変更される場合があります。

ストーリー再生

  • Project Root ごとに作品を分け、Markdown ファイルを 1 シーンとして再生
  • 単独行 Wiki リンク（例: [[次へ]]）を選択肢ボタンとして表示
  • flags / vars の更新と、本文への {{vars.hp}} などの埋め込み表示
  • 条件付き選択肢・本文の条件表示、frontmatter gate、乱数分岐
  • gamebook / adv の 2 種類の表示テンプレート
  • 背景画像、キャラクター表示、fade / typewriter 演出
  • 段階表示（display_mode: all / append / replace）

制作支援

  • Story Map — シーン構造の可視化、リンク編集、Play from here
  • Route View — ルートの確認・編集（Story Map と連動）
  • 構文チェック、補完、Syntax Help、Debug Overlay
  • プレビュー表示設定を「作品標準スタイル」として保存

シーンは <projectRoot>/scenes/ 配下に置く運用を想定しています。

公開前の注意点

  • 名称は仮で、公開時に変更される可能性があります
  • Back ボタン、scene_id 指定での直接遷移など、一部機能は公開後も順次対応予定
  • Community Plugin としての公開前レビュー・実機検証を進めています
