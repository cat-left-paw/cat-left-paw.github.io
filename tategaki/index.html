Tategaki Vertical writing editor for Obsidian

Obsidian 上で Markdown を縦書きレイアウトで編集・閲覧できるプラグインです。デスクトップ版 Obsidian 向けです。

デスクトップ専用 — Windows / macOS / Linux の Obsidian で利用できます。モバイル版 Obsidian には対応していません。

主な特徴

  • Obsidian の Markdown をそのまま縦書きで編集・閲覧
  • Writing & Reference モード、Book モードなど複数の表示モード
  • ルビ（青空文庫形式）・縦中横（TCY）のサポート
  • 縦書き向けのキーボード操作や Typewriter scroll
  • アウトライン、見出し折りたたみ、リスト編集の補助

インストール方法や詳細は GitHub の README / INSTALL を参照してください。

インストール

Obsidian の「コミュニティプラグイン」から「Tategaki」を検索してインストールするのが最も簡単です。

  1. Obsidian の設定を開く
  2. 「コミュニティプラグイン」→「閲覧」で Tategaki を検索
  3. インストールして有効化
